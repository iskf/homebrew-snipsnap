# Homebrew SnipSnap

Official Homebrew Tap for [SnipSnap](https://github.com/iskf/SnipSnap) — Native macOS screenshot, pinning, OCR, and Safari-style in-place translation tool.

## Installation

```bash
brew install --cask iskf/snipsnap/snipsnap
```

Or add the tap first:

```bash
brew tap iskf/snipsnap
brew install --cask snipsnap
```
